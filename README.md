7 个公开源、3465 条直播流逐条实测后筛出的可用列表。

## 只需要这一条

```
https://macno1.github.io/cn-tv/zh.m3u
```

TiviMate：`Settings → Playlists → Add playlist → M3U playlist` → 粘贴 → Done。

**一个文件里就有全部 6 组：**

| 组 | 频道 | 线路 |
|---|---|---|
| ① 香港（RTHK 31-35 / HOY 76-78 / TVB翡翠台 / 明珠台 / 有线新闻） | 21 | 28 |
| ② 凤凰（中文 / 资讯 / 香港） | 3 | 11 |
| ③ 央视（CCTV-1 ~ 17 + 4K + 5+ / CGTN 系列 / 央视付费频道） | 43 | 83 |
| ④ 卫视（湖南 / 浙江 / 江苏 / 东方 / 广东 / 深圳 / 山东 / 河南 …） | 40 | 101 |
| ⑤ 港澳台 / 海外中文 | 15 | 15 |
| ⑥ 地方台 / 城市台（浙江台全套 / 广东体育 / 深圳电视台 / 哈尔滨 …） | 146 | 160 |
| **合计** | **268** | **398** |

每个频道最多保留 4 条线路，**默认播放的那条就是该频道质量最好的线路**。
组内按**频道名称排序**（央视严格 `CCTV-1 → 2 → … → 17`），不再按画质乱跳。

> **为什么只有一个文件**
> TiviMate 免费版只允许添加 **1 个**播放列表（无限个需要 Premium）。而 M3U 的 `group-title`
> 本身就会在播放器里生成分组树 —— "频道太多"不是问题，没人会去翻 ⑥ 组，除非他自己点开。
> 所以拆成多个文件只有坏处：对免费用户等于"每次换一份都得先删掉现在的"。
>
> **高清为什么不单独成组**
> 同一频道名若出现在两个分组里，TiviMate 会把它们合并成一个频道，然后"输掉"的那个分组
> 看起来就缺台。所以画质用频道名后缀 `·高清` 表达，并把高清线路排在**该频道内部第一位** ——
> 点开这个台，默认播的就是它最好的那条。不需要第二个文件。

## 标记说明

- **⚠** = 裸 IP 中转源（个人美国 VPS 中转）。能用，但晚高峰会卡 —— 这正是"晨瑞电视"卡顿的同一个物理原因。
- **·高清** = 该线路实测 ≥1080P。取自 HLS 主播放列表的 `RESOLUTION` 字段，**不是**频道名里自称的高清。
  低于 1080P 或测不出的**一律不标** —— 早先按 `·1080P/·720P` 逐档标注，列表太乱，已撤掉。
- 组内排序：**按频道名称**（简体，CCTV 用拼音/数字序）。画质只在后台决定"默认播哪一条"，
  不影响排序 —— 一条经美国 VPS 中转的 1080P 仍然会卡，稳定性永远优先于分辨率。

## 同一电视台只有一个名字

上游不同列表对同一台的命名不一致，会让一台显示成两个半残频道。已做归并：

| 上游写法 | 归并后 |
|---|---|
| `RTHK31` / `RTHK TV 31` / `RTHK TV31` | `RTHK TV 31` |
| `翡翠台` / `Jade` / `TVB翡翠台` | `TVB翡翠台` |
| `鳳凰衛視` / `凤凰卫视台` / `凤凰中文台` | `凤凰中文` |
| `凤凰资讯台` / `凤凰香港台` | `凤凰资讯` / `凤凰香港` |
| `CGTN英语` / `CGTN记录` | `CGTN` / `CGTN纪录` |
| `CCTV-11 戏曲`(英文条目) / `CCTV怀旧剧场` 等 12 个英文频道 | 对应中文名，其中 4 个与已有中文条目**其实是同一个台，已合并** |

**全部台名已转简体**，上游的繁体写法（`鳳凰衛視`）与简体写法会归并成同一个频道。

## 限制（如实说明）

- **CCTV-1 ~ CCTV-8 主力台没有官方 CDN 直连**，只能走 ⚠ 中转。官方直连的只有 CCTV-4 / 9 / 15 / 17 和 CCTV+ 少数几条。
- **② 凤凰组是全网最弱的一组（只有 64%）**，公开源里的凤凰全是第三方中转。要看稳定的凤凰中文台 / 资讯台 / 香港台，用官方「凤凰秀 TV 版」。
- **台湾主流台只有 ⚠ 中转的那几个**（台视新闻 / 民视新闻 / 三立戏剧 / 东森洋片 / 八大戏剧台 / 纬来精采），稳定性一般。台视 / 中视 / 华视 / 民视的**官方 24 小时直播在 YouTube**，那个不会卡。
- 公开源平均 **2-4 周**失效一批，需定期重跑脚本刷新。
- 央视全套 + 凤凰最稳的看法是官方 App：央视频TV（电视商店搜 `YSPTV`）、凤凰秀 TV 版。
