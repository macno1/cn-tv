**每个频道只有一条线路，而且这条线路是被真实下载验证过的。**

> **为什么每台只有一条**
> 早先每个频道给 4 条线路，想法是"播放器会把同名频道合成一个台、可以切线路"。
> **TiviMate 不这么做** —— 每一个条目就是列表里的一个频道，所以 4 条线路 = 4 个同名频道。
> 现在每个频道只留**实测能播且质量最好的那一条**。
>
> **为什么只有 3 组（原来 6 组）**
> 6 组意味着侧栏一排长标签（"⑤ 港澳台 / 海外中文"光名字就 11 个字），而它区分的并不是用户真的会做的区分。
> 3 个短分组用遥控器更好按，顺带消掉一类通病：同一个频道出现在两个分组里时，播放器会把它们合并，
> 另一个分组就默默少台。

## 这一版做了什么（2026-09-29）

不只是"能连上"，而是**逐条把视频切片下载下来验证能不能出画面**：

| 检查 | 结果 |
|---|---|
| 抓取去重 | 3593 条 |
| 能连上（HTTP 有响应） | 754 条（21%） |
| **真的能出画面** | **583 条（77%）** —— 其余是失效 / 静止画面 / 切片过小 |
| 最终收录 | 231 条（每台一条） |

被剔除的"能连上但看不了"分三类，正是"连上了却显示信号源失效"的真凶：

- **静止画面 53 条** —— 相邻两个切片**字节完全相同**（真实视频不可能），或切片干脆是一张图片。
  例如 `php.jdshipin.com` 上的凤凰卫视台 / 凤凰资讯台 / 澳门卫视，直接返回**一张占位图片**。
- **失效 116 条** —— 清单或切片取不到。
- **切片过小 2 条** —— 比如江苏卫视的切片只有 172 字节。

**没有二次复测就不会有这份列表。**首轮测完 RTHK 31-35 和 HOY 全被判死，手工连测 5 次却是 5/5 成功
（直播清单在编码器重启的瞬间会短暂为空，CDN 在高并发下也会拒几个请求）。加三重试复测后它们全部恢复。

## 标记说明

**频道名后面只有一种标记：**

- **·高清** = 该线路实测 ≥1080P。取自 HLS 主播放列表的 `RESOLUTION` 字段，**不是**频道名里自称的高清。
  低于 1080P 或测不出的**一律不标** —— 早先按 `·1080P/·720P` 逐档标注，列表太乱，已撤掉。

**中转源不打标记**，直接不收录。裸 IP 中转（个人 VPS 上架的转码站）晚高峰必卡，正是"晨瑞电视"卡顿的
同一个物理原因，所以只在没有更好的线路时才留，并且一定是该频道唯一的那条。

组内排序：**按频道名称**（简体，CCTV 用数字序）。

## 同一电视台只有一个名字

上游不同列表对同一台的命名不一致，会让一台显示成两个半残频道。已做归并：

| 上游写法 | 归并后 |
|---|---|
| `RTHK31` / `RTHK TV 31` / `RTHK TV31` | `RTHK TV 31` |
| `翡翠台` / `Jade` / `TVB翡翠台` | `TVB翡翠台` |
| `鳳凰衛視` / `凤凰卫视台` / `凤凰中文台` | `凤凰中文` |
| `凤凰资讯台` / `凤凰香港台` | `凤凰资讯` / `凤凰香港` |
| `CGTN英语` / `CGTN记录` | `CGTN` / `CGTN纪录` |
| 12 个英文条目（`CCTV-11 戏曲` 等） | 对应中文名，其中 4 个与已有中文条目**其实是同一个台，已合并** |

**同一条线路的显示名完全一致**（包括 `·高清` 后缀按"整个频道"而不是"单条线路"决定）——
否则 `RTHK TV 31` 和 `RTHK TV 31 ·高清` 会被播放器当成两个台。

## 限制（如实说明）

- **部分大台这版没有收录**：CCTV-2 / 5 / 8、四川卫视、东南卫视、广东体育 / 新闻 / 少儿、河北系等
  的公开源**目前全部失效**（实测这些线路的服务器直接 404，不是我们筛掉的）。下一个能用的会补回来。
- **CCTV 主力台基本没有官方 CDN 直连**，能用的多为中转。官方直连稳定的只有 CCTV-4 / 9 / 16 / 17 和 CCTV+。
- **凤凰只剩 3 个台且靠中转**。要看稳定的凤凰，用官方「凤凰秀 TV 版」。
- **台湾台在公开源里基本没有**（现有：台视新闻 / 民视新闻 / 三立戏剧 / TVBS新闻台 / 纬来精采 / 人间卫视）。
  台视 / 中视 / 华视 / 民视 / TVBS / 三立 / 东森的**官方 24 小时直播都在 YouTube**，画质最好。
  ⚠️ 但 YouTube 的直播地址**约 5 小时就失效、且绑定生成时的公网 IP**，所以**不能收进这份列表**
  （收了半天后整份列表就带毒）。想在电视上看这些台，装一个 YouTube 客户端（如 SmartTube）更省心。
- **本列表的源都是实时流、不含回看数据**，所以播放器里的"时移 / 回看"永远是空的。这是源的固有限制。
- 公开源平均 **2-4 周**失效一批，需定期重跑刷新。
- 央视全套 + 凤凰最稳的看法是官方 App：央视频TV（电视商店搜 `YSPTV`）、凤凰秀 TV 版。

内容仅为公开可访问的直播流地址。
