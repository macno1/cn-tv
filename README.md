| ③ 地方台 | 城市台 / 省级地面频道（浙江台全套 / 广东体育 / 深圳电视台 / 哈尔滨 …） | 146 | 160 |
| **合计** | | **262** | **398** |

每个频道最多保留 4 条线路，**默认播放的那条就是该频道质量最好的线路**。
组内按**频道名称排序**（央视严格 `CCTV-1 → 2 → … → 17 → 4K → 5+`），不再按画质乱跳。

> **为什么只有一个文件**
> TiviMate 免费版只允许添加 **1 个**播放列表（无限个需要 Premium）。而 M3U 的 `group-title`
> 本身就会在播放器里生成分组树 —— "频道太多"不是问题，没人会去翻 ③ 组，除非他自己点开。
> 所以拆成多个文件只有坏处：对免费用户等于"每次换一份都得先删掉现在的"。
>
> **为什么只有 3 组（原来 6 组）**
> 6 组意味着侧栏一排长标签（"⑤ 港澳台 / 海外中文"光名字就 11 个字），而它区分的并不是用户真的会做的区分。
> 3 个短分组用遥控器更好按，顺带消掉一类通病：同一个频道出现在两个分组里时，播放器会把它们**合并成一个**，
> 另一个分组就默默少台。分组越少，撞上这事的概率越低。
>
> **高清为什么不单独成组**
> 同一频道名若出现在两个分组里，TiviMate 会把它们合并成一个频道，然后"输掉"的那个分组
> 看起来就缺台。所以画质用频道名后缀 `·高清` 表达，并把高清线路排在**该频道内部第一位** ——
> 点开这个台，默认播的就是它最好的那条。不需要第二个文件。

## 标记说明

**频道名后面只有一种标记：**

- **·高清** = 该线路实测 ≥1080P。取自 HLS 主播放列表的 `RESOLUTION` 字段，**不是**频道名里自称的高清。
  低于 1080P 或测不出的**一律不标** —— 早先按 `·1080P/·720P` 逐档标注，列表太乱，已撤掉。

**中转源已经不再打标记。** 理由：中转源本身就排在每个频道的**最后一位**，默认播的那条永远是更好的那条，
所以那个标记只是白占位置。需要时**长按 `OK` 打开线路列表**，排在后面的几条就是中转线路。

组内排序：**按频道名称**（简体，CCTV 用拼音/数字序）。稳定性只在后台决定"默认播哪一条"，
不影响排序 —— 一条经美国 VPS 中转的 1080P 仍然会卡，稳定性永远优先于分辨率。

## 同一电视台只有一个名字

上游不同列表对同一台的命名不一致，会让一台显示成两个半残频道。已做归并：

| 上游写法 | 归并后 |
|---|---|
| `RTHK31` / `RTHK TV 31` / `RTHK TV31` | `RTHK TV 31` |
| `翡翠台` / `Jade` / `TVB翡翠台` | `TVB翡翠台` |
| `鳳凰衛視` / `凤凰卫视台` / `凤凰中文台` | `凤凰中文` |
| `凤凰资讯台` / `凤凰香港台` | `凤凰资讯` / `凤凰香港` |
| `CGTN英语` / `CGTN记录` | `CGTN` / `CGTN纪录` |
| 12 个英文条目（`CCTV-11 戏曲` 等） | 对应中文名，其中 4 个与已有中文条目**其实是同一个台，已合并** |

**全部台名已转简体**，上游的繁体写法（`鳳凰衛視`）与简体写法会归并成同一个频道。

## 限制（如实说明）

- **CCTV-1 ~ CCTV-8 主力台没有官方 CDN 直连**，只能走中转。官方直连的只有 CCTV-4 / 9 / 15 / 17 和 CCTV+ 少数几条。
- **凤凰是全网最弱的一组**（公开源里的凤凰全是第三方中转，可连率约 64%）。要看稳定的凤凰中文台 / 资讯台 / 香港台，用官方「凤凰秀 TV 版」。
- **台湾主流台大多也只能走中转**（台视新闻 / 民视新闻 / 三立戏剧 / 东森洋片 / 八大戏剧台 / 纬来精采），稳定性一般。台视 / 中视 / 华视 / 民视的**官方 24 小时直播在 YouTube**，那个不会卡。
- **HLS 本身的限制**：本列表的源都是实时流、不含回看数据，所以**播放器里的"时移 / 回看"永远是空的**。这不是设置问题，公开免费流没有这个数据。
- 公开源平均 **2-4 周**失效一批，需定期重跑脚本刷新。
- 央视全套 + 凤凰最稳的看法是官方 App：央视频TV（电视商店搜 `YSPTV`）、凤凰秀 TV 版。
