```
https://macno1.github.io/cn-tv/zh.m3u
```

| ⑤ 港澳台 / 海外中文（TVBS-Asia / 澳门 / 新加坡 Channel 8 …） | 23 | 23 |
| ⑥ 地方台 / 城市台（浙江台全套 / 广东体育 / 深圳电视台 / 哈尔滨 …） | 146 | 160 |

每个频道最多保留 4 条线路，**默认播放的那条就是该频道质量最好的线路**。

> 为什么只有一个文件：TiviMate 免费版只允许添加 **1 个**播放列表（无限个需要 Premium）。
> 而且 M3U 的 `group-title` 本身就会在播放器里生成分组树 —— "频道太多"不是问题，
> 没人会去翻 ⑥ 组，除非他自己点开。所以拆成多个文件只有坏处，没有好处。

## 标记说明

- **⚠** = 裸 IP 中转源（个人美国 VPS 中转）。能用，但晚高峰会卡 —— 这正是"晨瑞电视"卡顿的同一个物理原因。
- **·1080P / ·4K** = **实测**画质，取自 HLS 主播放列表的 `RESOLUTION` 字段，**不是**频道名里自称的高清。
- 组内排序：稳定优先（官方 CDN 直连 → ⚠ 中转），其次画质。**高清线路不会排在中转线路前面** ——
  一条经美国 VPS 中转的 1080P 仍然会卡，稳定性永远优先于分辨率。

  HLS 规范里**没有**分辨率字段，如实标为未知（不猜）

## 限制（如实说明）

- **CCTV-1 ~ CCTV-8 主力台没有官方 CDN 直连**，只能走 ⚠ 中转。官方直连的只有 CCTV-4 / 9 / 15 / 17 和 CCTV+ 少数几条。
- **② 凤凰组是全网最弱的一组**（10/13），公开源里的凤凰全是第三方中转。要看稳定的凤凰中文台 / 资讯台，用官方「凤凰秀 TV 版」。
- **台湾主流台**（台视 / 中视 / 华视 / 民视 / 东森 / 三立）公开源里没有，只能走官方 YouTube 24h 直播。
- 公开源平均 **2-4 周**失效一批，需定期重跑脚本刷新。
- 央视全套 + 凤凰最稳的看法是官方 App：央视频TV（电视商店搜 `YSPTV`）、凤凰秀 TV 版。
