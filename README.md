## 实测数据

- 3465 条去重 → 668 条可连（19%）
- 筛选后精简版复测：204 条线路可连 **194 条（95%）**
- 已剔除：蜻蜓FM 广播音频流（电视上只有黑屏）、宗教/购物/宠物等噪音台
- 香港组 RTHK 31-35、HOY 76-78 实测 **1080P**，且均为官方 CDN 直连（Akamai / hoy.tv）
- 画质覆盖：HLS 清单直接确认 59 条 + 地址推断 35 条 = 94 条；其余公开源用的是单档 media 播放列表，HLS 规范里**没有**分辨率字段，如实标为未知

## 限制（如实说明）

- **CCTV-1 ~ CCTV-8 主力台没有官方 CDN 直连**，只能走 ⚠ 中转。官方直连的只有 CCTV-4 / 9 / 15 / 17 和 CCTV+ 少数几条。
- **台湾主流台**（台视 / 中视 / 华视 / 民视 / 东森 / 三立）公开源里没有，只能走官方 YouTube 24h 直播。
- 公开源平均 **2-4 周**失效一批，需定期重跑脚本刷新。
- 央视全套 + 港澳凤凰的最稳看法是官方 App：央视频TV（电视商店搜 YSPTV）、凤凰秀 TV 版。
